多次元配列はテンソルと呼ばれる。  
np.dotは、@と同じ。  
ベクトルに対して@は、内積。スカラーになる。  
行列に対して@は、(A,B) @ (B,C) = (A,C)になる。  
要素ごとの積はアダマール積。  

x = (  
    身長,  
    体重,  
    hoge,  
)  
のとき、xに関する正規分布は  
N(x; μ, Σ) = 省略  
μは平均ベクトル。  
Σは(先ほどまでは小文字のσが標準偏差だったが、)共分散行列。  
共分散行列は、対角成分が「分散」、非対角が「共分散」です。  
|Σ|は、「行列式」といい、大学で習うようにたすきに計算してスカラーが得られるやつ。  
逆行列は、元の行列にかけると単位行列になるもの。単位行列は対角が1で、以外が0のもの。  
共分散行列 = [  
    [xの分散,                  xとyが正の相関か負の相関か],  
    [xとyが正の相関か負の相関か, yの分散                 ]  
]  
ということ。  

ベクトルや行列に対する微分は勾配(gradient)とも呼ばれる。  

1次元の時のように最尤推定の計算をすると、  
μバーベクトル = サンプル平均  
Σバーベクトル = (1/N) * SUM((xn - μ^) * (xn -μ^)T)　サンプルとサンプル平均の差のベクトルどうしを(転地して)掛けたもの、をサンプル数で割る  
だけになる。  

とまぁこのように、平均μと共分散行列Σ(1次元の時は標準偏差σ)が求まれば、多次元だとしてもサンプルにフィットするパラメータだとすることができる。  
多次元だとしてもサンプルからフィット学習してパラメータを求めて、母集団の分布が求まった。のでこれに従うデータを生成できますと。
